# Bridge Monitor — МАДИ

Учебный командный проект: **«Веб-приложение для мониторинга состояния мостовых сооружений для ГБУ „Автомобильные дороги“»**.

## Состав команды
- Сайби Ахмед Ясин — разработка пользовательского интерфейса (UI/Frontend)
- Хашпаков Амир Бесланович — модуль сбора данных
- Кубикильма Нсинги Лонги — модуль анализа данных
- Саного Хабибату — модуль визуализации данных
- Тиффо Тепуно Гаррис Джовик — модуль формирования отчётности

## Возможности
- единый реестр мостовых сооружений;
- карточка каждого объекта с техническими характеристиками;
- поиск и фильтрация;
- регистрация обследований;
- история обследований и дефектов;
- индекс состояния и уровень риска;
- аналитические диаграммы;
- географическая привязка объектов;
- переход к объекту в Яндекс Картах;
- сводная отчётность и экспорт CSV;
- светлая и тёмная темы интерфейса.

## Запуск
1. Запустите `setup.bat` один раз.
2. Запускайте `Bridge Monitor.bat`.
3. Откройте `http://127.0.0.1:5000`.

Стек: Flask, SQLite, HTML/CSS, JavaScript, Chart.js.
